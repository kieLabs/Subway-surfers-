# Subway Surfers – GamerKie Edition (3D GLB Web Game)

A complete 3D Subway Surfers-style endless runner built with **Three.js** and your custom **14 GLB 3D assets**, ready for GitHub Pages and Blogger iframe embedding.

## Folder Structure
- `index.html` — Complete responsive 3D game engine (Mobile Swipe + PC Keyboard, HUD, Power-ups, Shop, Web Audio SFX & BGM, `localStorage` save system).
- `models/` — All 14 individual `.glb` 3D assets (`01_gold_coin.glb` through `14_spray_paint_can.glb`).

## How to Deploy on GitHub Pages
1. Create a new repository on GitHub (e.g., `Subway-Surfers-GamerKie`).
2. Upload `index.html`, `README.md`, and the entire `models/` folder (keeping the `models/` folder path intact).
3. Go to **Settings → Pages → Branch: main / (root)** and click **Save**.
4. Open your live GitHub Pages URL (`https://kielabs.github.io/Subway-Surfers-GamerKie/`) or embed it inside a Blogger post using a responsive `<iframe>`.
